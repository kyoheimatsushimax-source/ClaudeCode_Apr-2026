# 関東マンション割安マップ

関東近郊（1都3県中心）の新築・中古マンション（購入）および賃貸マンションを
地図上にマッピングし、**相場より割安な物件を発見する**ためのローカルアプリです。

- 国交省「不動産情報ライブラリ」の成約・取引価格データをエリア相場の基準とし、
  掲載中物件の㎡単価が相場からどれだけ乖離しているかをスコア化（0〜100）
- Leaflet + OpenStreetMap の地図に、割安度で色分けしたマーカーとエリア相場
  ヒートマップを表示
- バックエンドは Python（FastAPI + SQLite）、フロントはビルド不要の静的ページ

## セットアップ

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

Python 3.10 以上が必要です。フロントエンドのライブラリ（Leaflet）は
`frontend/vendor/` に同梱済みで、地図タイル以外は完全にオフラインで動きます。

合成データで一通りの機能を確認できます:

※ デモの成約データは**実データではありません**（`app/demo_data.py` で生成）。

## APIキーの取得（実データを使う場合）

1. [不動産情報ライブラリ](https://www.reinfolib.mlit.go.jp/) の
   「API操作説明」ページから **API利用申請** を行う（無料）
2. メールで届いた API キー（サブスクリプションキー）を環境変数に設定:

```bash
export REINFOLIB_API_KEY="あなたのAPIキー"
```

## 実データでの使い方

```bash
# 1. 成約・取引価格データを取得（1都3県 × 指定期間。四半期更新）
python -m app.cli fetch --from 2022Q3 --to 2025Q2

# 2. 掲載物件を CSV / JSON でインポート（住所からジオコーディングされる）
python -m app.cli import my_listings.csv

# 3. エリア統計・トレンド回帰を計算（--geocode-areas で地区代表点も補完）
python -m app.cli stats --geocode-areas

# 4. 割安スコアを計算
python -m app.cli score

# 5. サーバ起動
python -m app.cli serve
```

物件を追加・更新したら 3〜4 を再実行してください。

### 掲載物件 CSV のフォーマット

ヘッダ必須。列の例は `data/sample/sample_listings.csv` を参照。

| 列 | 必須 | 説明 |
|---|---|---|
| `source_id` | ✔ | 取込元内で一意なID（再取込時は上書き） |
| `listing_type` | ✔ | `sale` / `rent`（`売買` `賃貸` などの表記も可） |
| `price` | ✔※ | 売買: 円 / 賃貸: 円/月。`price_man` 列（万円）でも可 |
| `area_sqm` | ✔ | 専有面積（㎡） |
| `building_year` | | 築年（西暦） |
| `prefecture` `municipality` `district` | | 都道府県 / 市区町村 / 町丁目。相場照合に使用 |
| `station` `walk_min` | | 最寄駅 / 駅徒歩分 |
| `lat` `lng` | | 緯度経度。無ければ `address` から国土地理院APIで補完 |
| `title` `url` `address` | | 表示用 |

## 割安スコアの仕組み

物件ごとに2指標を算出し、合成スコア（0〜100、高いほど割安）で色分けします。

1. **相場乖離率** — 同一エリア（町丁目）×築年帯×広さ帯の成約㎡単価中央値に
   対する掲載㎡単価の乖離(%)。サンプルが少ない場合は
   「地区×広さ帯 → 市区町村×築年帯×広さ帯 → … → 市区町村全体」の順に
   フォールバックし、**信頼度（高/中/低）とサンプル数**をカードに表示します。
2. **トレンド乖離率** — 過去3年の市区町村別㎡単価（四半期中央値）の回帰
   トレンドで相場を現在時点に補正した理論価格との乖離(%)。

合成: `スコア = 0.7 × 相場スコア + 0.3 × トレンドスコア`
（乖離 0% = 50点、-20% = 100点、+20% = 0点）

- **賃貸**は同じロジックを賃料㎡単価に適用します（相場は掲載中の賃貸物件から
  作成）。売買相場と賃料相場が両方あるエリアでは**想定表面利回り**を参考表示。
- 相場比 **-35% 以下 / +60% 以上**は外れ値（借地権・事故物件・入力ミス等の
  可能性）としてフラグ付けし、デフォルトで地図から除外（フィルタで表示可）。

## 地図UI

- マーカーは割安度で色分け（緑→黄→赤）・クラスタリング対応
- クリックで物件カード: 価格 / ㎡単価 / エリア相場中央値 / 乖離率 / スコア /
  築年 / 駅徒歩 / 掲載元リンク
- フィルタ: 購入・賃貸切替、価格帯、広さ、築年数、駅徒歩、市区町村、スコア下限
- エリア別㎡単価ヒートマップ（地区代表点の円で表示）レイヤ切替
- 割安上位ランキングパネル（クリックで地図移動）

### 掲載物件の取得元について

取得元は `ListingProvider` 抽象インターフェースで分離しており、サイト毎の
アダプタを差し替え・無効化できます。現在は**手動 CSV/JSON インポート**のみ
実装済みです。

スクレイピングアダプタを実装する場合（Phase 3）は
`PoliteScraperProvider` を基底とし、以下を必須とします:
robots.txt 遵守 / リクエスト間隔5秒以上 / User-Agent 明示 / リトライ上限 /
対象サイトの利用規約確認（問題があれば `enabled = False` で無効化）。
