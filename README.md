# 勤怠管理システム

Node.js + Express + SQLite で構築したシンプルな勤怠管理 Web アプリです。

## 機能

- **打刻** — 従業員を選択して出勤・退勤を記録
- **本日の勤怠** — 全従業員の当日状況をリアルタイム確認
- **勤怠履歴** — 期間・従業員で絞り込んで履歴を参照
- **月次集計** — 月ごとの出勤日数・総勤務時間を集計
- **従業員管理** — 従業員の追加・削除

## セットアップ

```bash
npm install
npm start
```

ブラウザで http://localhost:3000 を開いてください。

開発時（ファイル変更で自動再起動）:

```bash
npm run dev
```

## 技術スタック

| レイヤー | 技術 |
|---------|------|
| フロントエンド | HTML / CSS / Vanilla JavaScript |
| バックエンド | Node.js / Express |
| データベース | SQLite（better-sqlite3） |

## データ

初回起動時にサンプル従業員 3 名が自動登録されます。勤怠データは `attendance.db` に保存されます（.gitignore で除外済み）。
