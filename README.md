# かんたん家計簿

シンプルで一目で分かる、ブラウザだけで動く家計簿アプリ。

## 特徴

- **インストール不要**: `index.html` をブラウザで開くだけ
- **一目瞭然**: 月ごとの収入・支出・収支をひと目で確認
- **カテゴリ別ドーナツチャート**: 支出割合を可視化
- **予算設定 & 達成率バー**: カテゴリごとの月予算を設定し、使用状況をプログレスバーで表示 (80% で黄、100% 超で赤)
- **年間推移グラフ**: 直近12ヶ月の収入・支出・収支を折れ線で表示
- **月切り替え**: 過去・未来の月へワンクリック移動
- **データはローカル保存**: `localStorage` に保存されるため外部送信なし
- **エクスポート / インポート**: 明細と予算を JSON 形式でバックアップ可能

## 使い方

1. `index.html` をブラウザで開く
2. 種類 (支出 / 収入)、日付、カテゴリ、金額を入力して「追加」
3. 上部の `‹ ›` ボタンで月を切り替え

## カテゴリ

- **支出**: 食費・日用品・住居・光熱費・通信・交通・医療・娯楽・衣服・教育・その他
- **収入**: 給与・副業・ボーナス・臨時収入・その他
